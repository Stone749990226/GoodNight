# 晚安

面向 vivo 的本地 Android 作息监督工具。连接充电器后点击「我去睡了」，手机明显移动或倾斜时留下记录，解锁后手写原因；再次点击晚安重新守候，早上点击「我醒了」结束。

## 构建与安装

需要 Android SDK 35、JDK 17–21。当前电脑可使用 `C:\Program Files\Java\jdk-19`；不要用 Android Studio 自带的 JDK 25 运行 Gradle 8.7。

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-19'
# local.properties 中配置 sdk.dir，或设置 ANDROID_HOME。
.\gradlew.bat :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

安装包：`app/build/outputs/apk/debug/app-debug.apk`。包名 `com.stone.sleepguard`，最低 Android 10，目标 Android 15。个人侧载调试版本，不配置服务器或互联网权限。

## 第一次使用

1. 在设置页开启通知、悬浮提醒、电池优化豁免。
2. 在 vivo 系统设置允许后台运行、自启动，并在最近任务中锁定晚安。厂商设置不能仅凭普通 Android API 保证已开启。
3. 先运行「拿起检测自测」：静置3秒后拿起，按需要调整灵敏度。
4. 插电，点击「我去睡了」，15秒内轻轻放下手机。锁屏时记录活动，不亮屏或震动，解锁再显示原因输入框。
5. 填写原因后自由完成事情，再点击晚安；每次点晚安都重新检查充电。之后拔电仍继续监督。
6. 早上点击「我醒了」，选择真实感受；可调用系统相机拍照，预览分享图，再自行选择朋友发送。设置页可导出带 UTF-8 BOM 的 CSV。

## 记录含义

- 最终就寝是最后一次有效的本人声明，不代表实际睡着。中断后未再次点晚安时，不推算就寝时间。
- 醒来前5分钟内未填写原因的活动可归为起床操作；较早事件保留待补记。
- 记录间隔不等于睡眠时长。监控缺口、未完成记录不参加有效作息平均；达标要求就寝、起床都不晚于当晚目标。
- 亮灭屏与解锁只作辅助参考，不读取其他应用的触屏、消息或内容。
- 无账号、云端上传或自动发消息。照片位于私有文件目录，CSV与图片通过 FileProvider 临时分享。长分享图自动分页，保留完整原因。
- 已结束的一晚可以在记录页展开后编辑或删除：改最终就寝、点击醒来时间，修改中断原因，或移除误报的中断。删除前会列明同时移除的中断与事件数量，删除后可在提示条点「撤销」原样恢复。守候中的当晚需先点「我醒了」结束监控，才能编辑或删除。
- 记录页可切换最近7天、最近30天，或自定义起止日期；统计、趋势与分享都按当前范围计算。点汇总表里的任意一晚，会滚动到下面该晚的详情并展开。

## 技术与故障恢复

Kotlin / Compose / Material 3 / Room / DataStore。前台服务使用 `specialUse`，加速度计10Hz、低通重力估计。默认倾斜超过20°持续0.5秒，或去重力加速度超过1.5m/s²持续0.3秒触发。低、高档分别采用30°/2.2m/s²、12°/1.0m/s²。

仅放置倒计时和监控状态持有局部唤醒锁，保证本机非唤醒传感器在锁屏时继续上报；唤醒锁有10分钟超时保护，由服务按分钟续期，待解释、临时使用和起床状态释放。不持久化原始传感器流。醒来后注销监听并停止前台服务；界面刷新仅在页面可见时进行。服务每分钟保留存活时间，恢复时明确标记无法确认的监控缺口，绝不将断档当作睡眠。vivo 私有唤醒传感器未作为核心依赖。

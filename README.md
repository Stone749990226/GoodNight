# 晚安

面向 Android（vivo、小米/Redmi、OPPO 等）的本地作息监督工具。连接充电器后点击「我去睡了」，手机明显移动或倾斜时留下记录，解锁后手写原因；再次点击晚安重新守候，早上点击「我醒了」结束。

## 构建与安装

需要 Android SDK 35、JDK 17–21。当前电脑可使用 `C:\Program Files\Java\jdk-19`；不要用 Android Studio 自带的 JDK 25 运行 Gradle 8.7。

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-19'
# local.properties 中配置 sdk.dir，或设置 ANDROID_HOME。
.\gradlew.bat :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

安装包：`app/build/outputs/apk/debug/app-debug.apk`。包名 `com.stone.sleepguard`，最低 Android 10，目标 Android 15。个人侧载调试版本，不配置服务器或互联网权限。

## 第一次使用

1. 首次打开先选身份：我是 Stone / 我是 Fanny，选好后不可更改；之后在设置页开启通知、悬浮提醒、电池优化豁免，并在「邮件通知」里填发件邮箱、授权码、对方邮箱，先发一封测试邮件。
2. 在系统设置允许后台运行、自启动，并在最近任务中锁定晚安；小米/Redmi 还需把省电策略设为「无限制」。厂商设置不能仅凭普通 Android API 保证已开启。
3. 先运行「拿起检测自测」：等 3、2、1 倒计时结束后再拿起手机，确认能触发。设置页只提供自测，不暴露测量细节。
4. 插电，点击「和 Fanny 说晚安 💤 mua 💞」（Fanny 手机上会显示 Stone），先选今晚期待几点醒（默认沿用设置里的起床时间，也可只改这一晚），15秒内轻轻放下手机。锁屏时记录活动，不亮屏或震动，解锁再显示原因输入框。
5. 填写原因后自由完成事情，再点击晚安；每次点晚安都重新检查充电。之后拔电仍继续监督。
6. 早上点击「我醒了，去和 Fanny 说早安 ☀️」，选择真实感受；可调用系统相机拍照，预览分享图，再自行选择朋友发送。若到点还没醒，晚安会在目标起床时间后提醒，并在解锁时弹出提示。

## 记录含义

- 首页醒来状态会读取 `app/src/main/assets/quotes.json`：05:00–17:59 用 `morning`，18:00–04:59 用 `evening`；00:00–04:59 沿用前一晚的晚间句，05:00 才换日。每项是 `{"text":"正文","source":"出处"}`，正文下方用「—— 出处」显示。长句自动换行、页面可滚动，不截断；文件缺失或为空时回退「今天也要开心」。
- 中断填完原因后，如果 10 分钟内没有再次点「我去睡了」，会自动回到继续监控（SETTLING/MONITORING）；自动恢复不发送「再次晚安」邮件。10 分钟内手动点晚安仍会正常发送。
- 从首次点「我去睡了」到最终点「我醒了」不足 60 分钟的短记录不会生成；App 启动时也会自动清理历史里的这类短记录。
- 最终就寝取最后一次晚安确认；如果之后又拿起手机且没有再点晚安，最终就寝取最后一次中断结束、放下手机的时间，不再显示「—」。中断后重新点晚安会更新为更晚的时间。
- 离目标起床超过 3 小时，拿起手机必须写原因；进入起床窗口（目标前 3 小时起）后移动手机不再要求原因，先问「bb，醒了吗？🥺」：选「我醒了」再挑感受并结束；选「再睡会儿」则 10 分钟内不再弹、继续监控。到了目标时间还没确认也不会自动结束或发醒来邮件。
- 起床感受三选一：满血复活 ⚡ / 半梦半醒 🫠 / 困成小狗 🐶；记录页存短标签，邮件显示整句。感受必选，户外照片可选，可稍后在最近一晚补拍。
- 默认目标是 00:15 放下手机、08:30 起床；旧默认值（23:30/07:30）会在升级时自动迁移，已自定义的不改。
- 计划页：月份日历左右滑动切换月份、点日期查看当天计划和习惯；上方是计划，下方是习惯，右上角「+」选择新建计划或习惯。每个计划/习惯只占一行，点整行打开编辑，完成/加一次在右侧操作，删除在编辑弹窗里。
- 习惯支持每天、每周选几天、工作日（2026 法定节假日跳过），每天目标次数（例如喝水 8 次），最多 5 个提醒时段；提醒方式可选「通知」或「闹钟」。单次习惯打勾，计数习惯点「+1」。
- 习惯提醒：所有计时习惯达到目标后给对方发一封汇总邮件；某时段逾期 2 小时仍未达标单独发提醒；当天未全部达标，午夜发完成情况汇总。只存本机，不做双人共享清单。
- 监控缺口仍按记录时间计入作息平均；未完成、超过最长睡眠时长、或点击早安晚于目标 5 小时的记录不参与平均。中断后没有重新晚安时，用最后一次中断结束时间作为最终就寝。达标要求就寝、起床都不晚于当晚目标。
- 达标率只统计有效记录：最终就寝不晚于当晚目标、点击醒来不晚于当晚目标，两条都满足才算达标；目标在设置 →「目标作息」里配置，历史记录按各自当天的目标计算。
- 「最多睡眠时长」可在设置里调整（4–16 小时，默认 10）。超过该时长还没点我醒来的记录会保留，但标记为超长、不计入平均；事后在编辑里改对时间即可恢复。
- 到目标起床时间后 30 分钟仍未结束，会发一条「早上好」通知；解锁时优先弹出「我醒了 / 稍后 / 打开晚安」的悬浮卡片，并尝试把晚安页面带到最前。提醒每 30 分钟最多一次，点我醒了后全部取消。
- 邮件事件：说晚安、再次晚安、半夜拿起（含原因）、我醒了、超时未醒、超过最长时长、监控中断，均即时发送；离线进队列重试。发送成功后用 Toast 提示「邮件已发送给 {对方}」。邮件里的姓名由首次选择的身份自动决定；授权码用 Android Keystore 加密只存本机，覆盖更新保留。
- 分享图的落款是「晚安，分享给 {对方}」，按首次选择的身份自动生成名字。
- 亮灭屏与解锁只作辅助参考，不读取其他应用的触屏、消息或内容。
- 无账号、无云端；邮件通过自己的 SMTP 直接发给对方，不含传感器原始数据。照片位于私有文件目录，分享图片通过 FileProvider 临时分享。长分享图自动分页，保留完整原因。
- 已结束的一晚可以在记录页展开后编辑或删除：改最终就寝、点击醒来时间，修改中断原因，或移除误报的中断。删除前会列明同时移除的中断与事件数量，删除后可在提示条点「撤销」原样恢复。守候中的当晚需先点「我醒了」结束监控，才能编辑或删除。
- 记录页可切换最近7天、最近30天，或自定义起止日期；统计、趋势与分享都按当前范围计算。点汇总表里的任意一晚，会滚动到下面该晚的详情并展开。

## 技术与故障恢复

Kotlin / Compose / Material 3 / Room / DataStore。前台服务使用 `specialUse`，加速度计10Hz、低通重力估计。灵敏度固定为高：倾斜超过12°持续0.5秒，或去重力加速度超过1.0m/s²持续0.3秒触发，设置页不提供调节，只保留前台自测。

仅放置倒计时和监控状态持有局部唤醒锁，保证本机非唤醒传感器在锁屏时继续上报；唤醒锁有10分钟超时保护，由服务按分钟续期，待解释、临时使用和起床状态释放。不持久化原始传感器流。醒来后注销监听并停止前台服务；界面刷新仅在页面可见时进行。服务每分钟保留存活时间，恢复时明确标记无法确认的监控缺口，绝不将断档当作睡眠。厂商私有唤醒传感器不作为核心依赖。
